**PR Title:** feat: CSV to Markdown converter

**The Problem Solved:** Provides a fast, client-side utility for converting CSV text into formatted Markdown tables, eliminating the need to write them by hand or rely on external ad-heavy tools.

**Visuals:** [Screenshot](/home/jules/verification/screenshots/verification.png)

**Implementation Journey:**
- Executed Pre-Flight Check to ensure no duplication of the CSV to Markdown tool.
- Brainstormed and logged 3 distinct feature ideas/architectures in internal logs.
- Wrote robust, zero-dependency CSV parsing logic handling quotes and unquoted values.
- Built a minimalist `CsvToMarkdown` UI component matching existing Shadcn paradigms (Standard side-by-side layout).
- Implemented comprehensive Vitest test coverage for parsing edge-cases and UI interactions.
- Resolved testing infrastructure issues specific to mocking clipboard interaction.
- Verified visual accuracy via Playwright.

**Tradeoffs & Assumptions:**
- *Assumption:* Users want immediate feedback, so I bypassed adding a "Convert" button in favor of real-time conversion via `useEffect`.
- *Tradeoff:* I chose to write a custom CSV parser instead of adding a dependency like `papaparse` to adhere to "Simplicity First" since the use case is straightforward text conversion, not massive data processing.
- *Forced Variance:* Considered a file-upload approach, a single-textarea toggle approach, and a dual-textarea approach. Chose dual-textarea for instant visual feedback.

**Testing Instructions:**
1. Check out the branch: `git checkout feature/csv-to-markdown`
2. Start the dev server: `npm start`
3. Navigate to `#csv-to-markdown` under Developer Tools.
4. Input CSV data (try with quotes and commas) and observe the real-time Markdown output.
5. Click "Copy" and paste to verify clipboard functionality.
6. Run unit tests locally: `npm run test`
