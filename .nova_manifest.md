**PR Title:** feat: Binary Text Converter tool

**The Problem Solved:** Provides a quick conversion between UTF-8 text and binary representations, adding a useful text encoding tool to the application.

**Visuals:** [Screenshot](screenshot.png)

**Implementation Journey:**
- Analyzed existing tools and git branches to ensure no duplication.
- Created `BinaryTextConverter` component with a minimalist mode toggle UI using Shadcn components (verified their existence in `src/components/ui`).
- Integrated the component into `src/lib/tools.tsx` under Text & Encoding.
- Implemented unit tests for the conversion logic and UI using vitest and jsdom.
- Verified functionality and visual layout via Playwright screenshots.

**Tradeoffs & Assumptions:**
- Assumed the user wanted a new feature that matches the spirit of the existing utility tools.
- Evaluated Standard, Minimalist, and Lateral/Creative approaches; selected Minimalist (single toggleable form) to provide a clear user experience without auto-detection complexity.

**Testing Instructions:**
1. Check out the branch: `git checkout feature/binary-text-converter`
2. Start the dev server: `npm start`
3. Navigate to `#binary-text-converter` via the side nav.
4. Toggle between modes, enter text, and verify the live conversion output.
5. Run unit tests locally: `npm run test`
