PR Title: feat: Unit Price Calculator

The Problem Solved: Helps users figure out the better deal when grocery shopping by comparing two items based on their price and size.

Visuals: [Screenshot](unit-price-calculator.png)

Implementation Journey:
- Set up `UnitPriceCalculator` React component.
- Implemented state for two comparison items (price and size).
- Developed calculation logic to determine the unit price and best deal.
- Added UI utilizing the pre-existing shadcn/ui components (`Input`, `Label`, `Card`).
- Wrote and verified Unit tests using vitest.
- Ran playwright to generate UI screenshots.
- Updated the tool registry in `src/lib/tools.tsx`.

Tradeoffs & Assumptions:
- Standard Path was chosen. Minimalist natural language input was too complex and prone to edge-case parsing issues for a simple tool.
- Reused shadcn components to ensure the UI feels consistent with other calculators.

Testing Instructions:
1. Start dev server: `npm start`
2. Navigate to `#unit-price-calculator`.
3. Input price and sizes for Item A and Item B.
4. Verify the winner is correctly highlighted.
