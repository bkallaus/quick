**PR Title:** feat: Morse Code Translator tool

**The Problem Solved:** Provides a quick, real-time calculation tool to translate text into Morse code and vice-versa.

**Visuals:** [Screenshot](screenshot.png)

**Implementation Journey:**
- Investigated the existing utility tools and decided on a net-new Morse Code Translator feature.
- Created `MorseCodeTranslator` component using Shadcn UI textareas with bidirectional data-binding.
- Registered the new component in `src/lib/tools.tsx` within the `Text & Encoding` category.
- Fixed a vitest configuration issue and wrote comprehensive unit tests ensuring proper handling of valid and unknown characters.
- Verified visual layout and interactions with an automated Playwright script and screenshot validation.

**Tradeoffs & Assumptions:**
- Assumed real-time, bidirectional translation was the preferred UX.
- Brainstormed 3 options: Standard (two textareas), Minimalist (one textarea + toggle), Lateral (audio playback). Chose the Standard option to adhere to the "Simplicity First" philosophy and match the existing component style.
- Assumed standard vitest testing practices should be followed over manually mocking test dependencies for known pre-existing test suite failures, choosing to fix the tests that blocked the development pipeline.

**Testing Instructions:**
1. Check out the branch: `git checkout feature/morse-code-translator`
2. Start the dev server: `npm start`
3. Navigate to `#morse-code-translator` via the side nav under Text & Encoding.
4. Type text in the left area and verify Morse code appears on the right.
5. Edit the Morse code on the right and verify the text on the left updates accordingly.
6. Run unit tests: `npm run test`
