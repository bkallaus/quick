**PR Title:** feat: CSS Box Shadow Generator tool

**The Problem Solved:** Provides a quick, real-time visual tool to design and generate CSS box-shadow styles, allowing developers to see the output immediately and copy the CSS snippet.

**Visuals:** [Screenshot](/home/jules/verification/screenshots/verification.png)

**Implementation Journey:**
- Investigated the current tools and `src/components/ui` components, deciding to leverage the existing `Slider` component for a seamless UI.
- Created `CssBoxShadowGenerator` component using Shadcn UI components.
- Integrated the component into `src/lib/tools.tsx` under the `color-design` category.
- Implemented robust unit tests for the CSS string generation and UI interactions, verifying clipboard behavior via Vitest.
- Resolved a missing Vitest dependency to run the test suite locally.
- Verified functionality with Playwright end-to-end capture and visual screenshot review.

**Tradeoffs & Assumptions:**
- I considered 3 options for the Box Shadow Generator: Standard (sliders + copyable output), Minimalist (text inputs only), and Lateral/Creative (draggable light source). I chose the Standard approach because it aligns perfectly with existing simple utilities in the app while maximizing precision and usability via the `Slider` component.
- I assumed that a simple "inset" toggle, rather than multiple shadows in one tool, is sufficient for a quick developer utility.

**Testing Instructions:**
1. Check out the branch: `git checkout feature/css-box-shadow-generator`
2. Start the dev server: `npm start`
3. Navigate to `#css-box-shadow-generator` via the side nav.
4. Adjust the horizontal offset, vertical offset, blur radius, spread radius, and colors.
5. Verify the preview updates in real-time.
6. Click the copy button next to the CSS output and paste into an editor to confirm it matches.
7. Run unit tests locally: `npm run test`
