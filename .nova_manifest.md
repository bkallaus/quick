**PR Title:** feat: Set Operations tool

**The Problem Solved:** Provides a quick utility to compute Union, Intersection, and Difference between two line-separated lists. This is a common need when comparing arrays of data or extracting unique subsets without writing one-off scripts.

**Visuals:** [Screenshot](/home/jules/workspace/screenshot.png)

**Implementation Journey:**
- Verified no duplication by checking `git branch -a`.
- Outlined approach and brainstormed 3 architectural variants in `.logs/plan-logs.txt`.
- Chose a minimal UI approach with two textareas, a selector for the operation, and an output textarea.
- Developed `src/components/set-operations.tsx` using native JS `Set` methods.
- Wrote unit tests in `src/components/set-operations.test.tsx` verifying basic rendering and the default union operation.
- Added the feature to the `toolCategories` in `src/lib/tools.tsx`.
- Ran unit tests successfully to ensure the test suite is stable.
- Implemented and executed a Playwright script to verify visual rendering and integration.

**Tradeoffs & Assumptions:**
- Assumed standard line-separated input was the most universally applicable format for list data.
- Brainstormed 3 approaches (Standard multi-textarea, Minimal dropdown, Visual Venn Diagram). Selected the Minimal dropdown approach to avoid UI clutter and maintain a simple user experience aligning with other Quick Calculation tools.
- Assumed the test failure baseline in other test files was to be preserved per constraints. Testing only focused on the new feature file.

**Testing Instructions:**
1. Check out the branch: `git checkout feature/set-operations`
2. Run `npm install` and start the server: `npm start`
3. Navigate to `http://localhost:5173/quick/` and select "Set Operations" under "Text & Encoding".
4. Enter lists of items into List A and List B separated by newlines.
5. Select different operations (Union, Intersection, etc.) and observe the output.
6. Test functionality locally using: `npx vitest run src/components/set-operations.test.tsx`.
