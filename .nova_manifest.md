**PR Title:** feat: Meta Tags Generator

**The Problem Solved:** Provides a fast, easy way to generate standard HTML, Open Graph, and Twitter meta tags for web pages, improving SEO and social sharing setup.

**Visuals:** [Screenshot](/home/jules/quick/screenshot.png)

**Implementation Journey:**
- Designed the tool structure focusing on Title, Description, and Image inputs.
- Created `MetaTagsGenerator` using standard Shadcn UI components.
- Added comprehensive unit tests for generation logic and clipboard copy.
- Integrated the tool into `src/lib/tools.tsx`.
- Verified UI rendering via Playwright screenshot.

**Tradeoffs & Assumptions:**
- Assumed standard OG and Twitter Card tags were sufficient for most users.
- Chosen a single read-only textarea for output over separate copy buttons per tag type, adhering to Phase 3 "Simplicity First" rule.

**Testing Instructions:**
1. Check out the branch: `git checkout feature/meta-tags-generator`
2. Start the dev server: `npm start`
3. Navigate to the Meta Tags Generator tool.
4. Input sample text and verify the generated tags.
5. Click "Copy" and verify clipboard contents.
6. Run unit tests locally: `npm run test`
